Nayak

The existing Nayak website is linked at nayakandco.in. Scout is a separate application and is not a portfolio case study here.

Virality OS

A new frontend redesign and local interaction demonstration by Shivansh Nayak. It does not use a live AI service, collect payments or create accounts.

Fizzi Soda

Adaptation using the Fizzi Soda repository, its soda model and label textures. The frontend has been rebuilt without a CMS dependency, with a working local demo bag and flavour selector.

The Substance

Original The Substance by Paul Henschel. Original diamond model and photographic assets are used in a new frontend. Images credited upstream to Unsplash and Paul Henschel. New page structure, material controls, study dialogs and enquiry interface by Shivansh Nayak.

Sleepy

Original Sleepy by David Hernández. The original page structure, GSAP choreography, image sequences and cart foundation are retained. This adaptation adds portfolio navigation, route-safe assets, attribution and demo-specific messaging.
