What’s in it?

Fizzi is a fictional brand concept. Flavour names and pack sizes are illustrative; ingredient and nutrition information would be supplied by a real manufacturer before sale.

This adaptation is by Shivansh Nayak, using the open-source Fizzi Soda model, textures and creative foundation. Original assets and code retain their notices.
