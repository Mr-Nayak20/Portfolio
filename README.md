# Shivansh Nayak — front-end portfolio

A monochrome portfolio with six self-contained frontend showcases. The existing Nayak brand website is linked externally at https://nayakandco.in.

## Run

`npm ci` then `npm run dev`. Build with `npm run build`.

## Pages

- `/` — portfolio, with live project links and frontend case studies
- `/virality/` — redesigned creator website and local sample-outline studio
- `/fizzi/` — 3D soda storefront, flavour selection and persistent demo bag
- `/substance/` — visual studio, real-time material controls and editorial studies
- `/sleepy/` — adapted product narrative, frame sequences and demo shopping flow
- `/nocturne/` — full cinematic perfume website with ingredient chapters and demo bag
- `/velocity/` — full footwear website with X-ray, thermal and CAD lens controls
- `/credits/` — original sources, adaptation scope and licence notices

Virality's outline generator is a local frontend demonstration, not a live AI model. Store checkouts and drop registrations are demonstrations; no payments, orders or remote registration occur. Substance's enquiry form composes a mailto draft and does not send automatically.

Original foundations: Sammy212/fizzi-soda, drcmda/the-substance (Paul Henschel), lawxr/sleepy (David Hernández), and blendi-remade/dioramas (Blendi). Their notices are retained in `web/public/credits/`. Dioramas generated assets are CC BY 4.0 and credited on the pages.
